# CodeBro-Python 🐍

Welcome to **CodeBro-Python**! This repository contains my personal Python programming notes, which I created while learning Python through the **CodeBro Python Tutorial**.

The main purpose of this repository is to document my learning journey, organize important concepts, and keep track of the topics I have covered along the way.

These notes include explanations, syntax, code examples, important functions, and practical programming concepts that helped me understand Python better. They are written in a simple and beginner-friendly manner so that I can easily revisit topics whenever I need a quick revision.

## 📚 What's Inside?

- **Python Basics:** Introduction to Python, variables, data types, and basic syntax.
- **Operators:** Arithmetic, comparison, logical, and assignment operators.
- **Conditional Statements:** Using `if`, `elif`, and `else` to make decisions.
- **Loops:** Understanding `for` loops, `while` loops, and loop control statements.
- **Data Structures:** Working with lists, tuples, sets, and dictionaries.
- **Strings:** String manipulation, slicing, formatting, and built-in methods.
- **Functions:** Defining functions, passing arguments, returning values, and understanding scope.
- **Object-Oriented Programming:** Learning about classes, objects, inheritance, and other OOP concepts.
- **Modules and Libraries:** Understanding imports and using Python's built-in modules.
- **Practical Examples:** Small programs and code snippets to apply what I've learned.
